# Stock Quant API

## 接口列表

### 1. 获取股票数据
```
GET /stock/<symbol>
GET /stock/<symbol>/<period>
```

### 2. 模型训练
```
GET /train/<symbol>
```

### 3. 价格预测
```
GET /predict/<symbol>
```

### 4. 策略信号
```
GET /strategy/<symbol>
GET /intraday_strategy
```

### 5. 组合管理
```
GET /portfolio_strategy
GET /stocks
GET /select
```
